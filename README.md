# Beauty CRM

Локальная CRM для салона на Svelte 5, SvelteKit, TypeScript, PostgreSQL 18, Drizzle ORM и Better Auth. Авторизация выполняется по логину и паролю; оператор дополнительно вводит шестизначный код сотрудника. Электронная почта создаётся технически и не используется в интерфейсе.

## Локальный запуск

Нужны Node.js 24+, npm и запущенный Docker Desktop.

```powershell
npm install
Copy-Item .env.example .env
```

В `.env` задайте `BETTER_AUTH_SECRET` (случайная строка длиной не менее 32 символов), `SEED_ADMIN_PASSWORD` и `SEED_OPERATOR_PASSWORD`. Пример адреса БД уже соответствует `compose.yaml`.

```powershell
docker compose up -d
npm run db:migrate
npm run db:seed
npm run dev
```

Откройте <http://localhost:5173>. Тестовые логины: `admin` и `operator`. Пароли берутся из `.env`; код тестового оператора — `482731`. При входе оператор отмечает «Я вхожу как оператор».

Если хотите использовать подготовленное окружение этого рабочего каталога, зависимости, `.env`, миграции и тестовые данные уже созданы; достаточно `npm run dev` при запущенном Docker Desktop.

## Сценарии

- Администратор видит все записи и смены, подтверждает, редактирует, переносит, отменяет и удаляет записи. Также добавляет операторов, салоны, услуги и мастеров.
- Оператор видит только свои записи и смены. Для создания записи сначала открывает смену. В кабинете идут таймер и показатели текущей смены.
- Новая запись ожидает подтверждения администратора. Подтверждённая запись автоматически становится завершённой после времени визита. Обновление запускается при обращениях к приложению и фоновым процессом работающего сервера.
- Перед закрытием смены оператор видит итог и может скопировать его. После закрытия сессия завершается. Кнопка «Продолжить смену» возвращает в кабинет.
- Сумма и средний чек считаются по стоимости созданных записей, независимо от статуса оплаты. Это показатели записей, а не фактически полученных денег.

## Проверка и сборка

```powershell
npm run check
npm run build
npm run smoke
```

`smoke` запускается при работающем dev-сервере, проверяет вход, роли, смену, создание и подтверждение записи, создание оператора, автоматическое завершение и выход. Созданные им временные записи и оператор удаляются после успешной проверки.

После изменений в схеме БД создавайте миграцию через `npm run db:generate`, затем применяйте её через `npm run db:migrate`.
